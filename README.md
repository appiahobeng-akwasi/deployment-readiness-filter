# Deployment readiness filter

A single-page instrument for deciding whether a low-capacity state should deploy a given AI system — five questions, three of them gates, with three worked examples from Sierra Leone and an interactive self-assessment.

- `index.html` — the site, fully self-contained (fonts inlined, no dependencies, works offline)
- `Deployment_Readiness_Filter.md` — the source text

By Akwasi Appiah Obeng, July 2026.
